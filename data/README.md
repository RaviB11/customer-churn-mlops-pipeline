# Data

`raw/Telco-Customer-Churn.csv` — IBM Telco Customer Churn sample dataset
(7,043 customers × 21 columns), downloaded from
https://github.com/IBM/telco-customer-churn-on-icp4d (`data/Telco-Customer-Churn.csv`).
Licensed under CC BY 4.0; attribution: IBM.

Data version used for the committed results is recorded in `manifest.json`
(SHA-256 of the CSV) and logged as the `data_sha256` tag on every MLflow run.

`sample/` — eight customers from the trained model's holdout set with the `Churn`
column removed (`new_customers.csv`) and one as JSON (`customer.json`) for trying
the CLI and API. Rebuild after retraining with `python scripts/make_sample_customers.py`.

`warehouse/telco.db` is generated by `scripts/train.py` (not committed).
